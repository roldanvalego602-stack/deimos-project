# Plan B para la demo

- [ ] Video de la demo grabado (2 min) y copiado en dos dispositivos.
- [ ] Capturas de pantalla: mapa con ruta, EVA con barras, aviso de tormenta, ruta sugerida (P), resumen final.
- [ ] La app corre **sin internet** (Phaser, Leaflet y Chart.js están en `web/vendor/`): probar con el wifi apagado.
- [ ] Versión desplegada abierta en una pestaña y versión local lista (`Live Server`) en otra.
- [ ] Un astronauta de prueba: explorar desde la base central, colocar un waypoint con `M` y trazar la ruta con `P`.
- [ ] Si falla el navegador: mostrar el video y narrar encima. Si falla el audio: tener el guion impreso.
- [ ] Una persona controla el cronómetro y avisa a los 2:30.
